# Матрица окон провайдеров

Единственный ответ на «что можем собирать»: откуда берётся цифра, какие окна
отдаёт `GET /api/limits`, какие полосы рисует `GET /api/pace`, что видно на
карточке и что попадает на график «норма vs факт».

Полоса pace появляется только для оконного лимита с известным `used_percent`.
Одиночное окно подписано именем провайдера. Второй метр того же провайдера в
той же колонке подписан «провайдер · метр» и красится оттенком базового цвета.
Сброс в колонке — одна строка на провайдера (`windows.<окно>.resets[]`).
Полоса с `reset_at: null` в `resets[]` не входит.

| Провайдер | Источник | Окна `/api/limits` | Полосы `/api/pace` | Карточка | График | Пометка |
|---|---|---|---|---|---|---|
| `deepseek` | `api.deepseek.com/user/balance` + локальные snapshots | баланс по валюте | нет | баланс и расход 24ч/7д | нет | деньги, не окно |
| `openrouter` | `/api/v1/credits`, `/api/v1/key`, `/api/v1/activity` | кредиты аккаунта, лимит ключа | нет | кредиты или расход ключа | нет | деньги, не окно |
| `zai` | `GET /api/monitor/usage/quota/limit` | `session` (5h), `weekly`, `mcp` | `5h`, `weekly`. Если у 5h есть `used_percent`, а `reset_at` нет — полоса с `pace: "n/a"` и подписью «сброс не сообщается», без точки на оси нормы | короткий и неделя в теле; MCP только в деталях | 5h и неделя | MCP — счётчик запросов, не окно темпа |
| `commandcode` | `/alpha/billing/credits` (+ `/subscriptions`) | `session` (5h), `weekly`, `monthly` | `5h`, `weekly`, `monthly` (имя провайдера) | короткий, неделя, месяц | все три окна | |
| `kimi` | `GET /coding/v1/usages` | `session` (5h), `weekly` только если пришёл `limit_7d`, `monthly_total`, `monthly_code` | `5h`, `weekly` (если есть), monthly: `kimi · всего`, `kimi · code` | 5 ч в шапке; `месяц (всего)` и `месяц (code)` в теле карточки и строками в деталях | те же полосы, что в `/api/pace` | нет `limit_7d` → weekly `нет данных` |
| `opencode-go` | `GET /zen/go/v1/usage` | `session` (5h), `weekly`, `monthly` | `5h`, `weekly`, `monthly` (имя провайдера, одно окно) | короткий, неделя, месяц | все три окна | |
| `cursor` | Cursor dashboard usage API (session token) + CSV токенов цикла | `total`, `cursor_models`, `other_models` | только monthly: `cursor · модели`, `cursor · другие`. `total` полосой не становится | всего, Cursor-модели, другие модели в теле; токены по моделям в деталях | только колонка «месяц», две полосы | 5h и weekly: `нет данных` |
